## Task 4: WCAG AA contrast audit

**Files:** (audit only — may trigger edits to src/web/operator.css, src/web/public.css)

**What:**
Audit every text/background pair in the updated CSS for WCAG AA 4.5:1 compliance using a node script:

```bash
node -e "
const pairs = [
  {fg:'#EDF2F8', bg:'#0A0F16', label:'ink-1 on bg'},
  {fg:'#C2CDDD', bg:'#0A0F16', label:'ink-2 on bg'},
  {fg:'#8E9CB3', bg:'#0A0F16', label:'ink-25 on bg'},
  {fg:'#758199', bg:'#0A0F16', label:'ink-3 on bg'},
  {fg:'#525E75', bg:'#0A0F16', label:'ink-4 on bg'},
  {fg:'#081008', bg:'#7C5CFC', label:'dark text on accent'},
  {fg:'#0A0F16', bg:'#7C5CFC', label:'bg on accent (login btn)'},
  {fg:'#EDF2F8', bg:'#141822', label:'ink-1 on card'},
  {fg:'#8E9CB3', bg:'#141822', label:'dim on card'},
];
function sRGB(c){c/=255;return c<=0.04045?c/12.92:Math.pow((c+0.055)/1.055,2.4)}
function L(hex){const r=parseInt(hex.slice(1,3),16),g=parseInt(hex.slice(3,5),16),b=parseInt(hex.slice(5,7),16);return 0.2126*sRGB(r)+0.7152*sRGB(g)+0.0722*sRGB(b)}
let fail=0;
for(const p of pairs){const l1=L(p.fg),l2=L(p.bg);const ratio=(Math.max(l1,l2)+0.05)/(Math.min(l1,l2)+0.05);const pass=ratio>=4.5;console.log(pass?'PASS':'FAIL',ratio.toFixed(2),p.label);if(!pass)fail++}
process.exit(fail);
"
```

If any pair fails, adjust the foreground (ink token) or background (accent token) to pass.

**Why:** Accessibility is a hard gate. Every text/background combination must meet AA standards.

**Proof:** The node script above exits 0 (all pairs pass 4.5:1). No WCAG AA violations remain.
