# Phase 1 — UI Design Contract

> Visual and interaction contract for frontend phases. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

> **Phase scope: copy-only sweep.** No layout, color, component, DOM-id, class, API, metric, or storage changes.
> Phase 2 owns the theme. This contract locks copy tone/voice, placeholder conventions, string-length
> discipline, and the i18n mechanics procedure. Visual sections below document the INHERITED state as
> frozen — they prescribe "do not move", not a redesign.
>

> dashboard key table — no hierarchy change in this phase.

| Surface | Constraint |
|---------|-----------|
| Stepper labels (`setup.stepper.*`) | ≤ 24 characters — must fit the 3-step horizontal stepper |

| Button labels (primary/ghost) | ≤ 28 characters |
| Hint paragraphs (`*.hint`) | ≤ 160 characters |
| Validation / probe feedback lines | ≤ 120 characters |
| Destructive confirmation titles | ≤ 60 characters; body ≤ 200 characters |

"shared across all connected clients") rather than touching CSS. Wrap behavior of existing
surfaces is unchanged and must not be relied upon for new longer strings.

## Copywriting Contract

### Voice and Tone Rules (locked for this phase; source: CONTEXT.md + AGENTS.md invariants)

1. **Provider-neutral always.** Never name a vendor (NVIDIA, NIM), vendor key prefix semantics, or
   single-provider flows in user-visible copy. The product is OPENPROXY; upstream systems are "providers".
2. **Generic key noun is "API key".** Matches the existing "Client API key" precedent. Upstream keys are
   "API keys"; client credentials are "client API keys". Never "NIM API key(s)", "NIM key", or bare "key"
   where ambiguity with keyboard/map keys is possible (table headers, aria-labels).
3. **Factual hints stay factual.** Keep the `nvapi-…` placeholder (factually accurate example for the
   default group) and the 40-rpm default hint (factual default, still true).
4. **Placeholders are sacred.** `{n}`, `{username}`, `{last4}`, `{version}`, `{keys}`, `{status}` must
   survive verbatim in every edited `en` and every CLDR form. `{n}` counts are already locale-formatted.
5. **Data is never localized.** Model ids, client names, publisher names, `nvapi-…` literals, URLs,
   and every `nimproxy_*` series pass through untouched (AGENTS.md invariant 5).
6. **No new em-dashes.** Existing em-dashes in edited strings stay untouched (minimal churn per CONTEXT.md);
   no edited or new string may introduce one (COPY-03 gate).
7. **`desc` fields are translator instructions.** Update every `desc` that names NIM to provider-neutral
   wording with the same placeholder/CLDR guidance; English-only `one`/`other` notes stay accurate.
8. **Sentence case** for headings, buttons, and hints. Terminal punctuation: complete sentences end with
   a period; button labels, stepper labels, placeholders, and column headers take none.

## Placeholder and Plural Conventions (normative)

1. Every `{token}` present in the old `en` must be present in the new `en` — verified by
   `scripts/check_i18n.py` (placeholder-mismatch fixture family).
2. CLDR plural groups are edited as a unit: all six forms (`zero one two few many other`) change
   together; English `one` takes the singular, all others the plural. Never edit `other` alone.
3. `desc` fields document which placeholder is a count vs. pre-formatted text; preserve that distinction.
4. `aria-label` / `placeholder` catalog entries (`data-i18n-attr`) follow the same replacement rules —
   assistive copy is user-visible copy.
5. `en-XA` pseudolocale must render the edited surfaces as part of phase proof (CONTEXT.md locked).

---

## i18n Mechanics Contract (normative procedure — executor follows exactly)

1. **Catalog ids frozen.** `data-i18n` keys, DOM ids, `data-*` attributes, CSS classes, sort keys, and
   config keys do not move (AGENTS.md invariant 6). Reword `en`/`desc` values only; never rename keys
   (even `…nim_key_count…` — the name is an identifier, not copy).
2. **Hash refresh.** Every edited `en` gets a fresh `sha256(en)[:8]` hash (`src/web/locales/en-US.json`;
   rule enforced at `scripts/check_i18n.py:1442`). Hashes are recomputed, never hand-written.
3. **Fixture regen atomically with the copy edit.** Run `scripts/locale_v1.py --update-public` to
   regenerate `tests/fixtures/locales/public-en-US.json` in the same change — catalog + fixtures land
   together so no intermediate state has stale hashes.
4. **Gates green.** `scripts/check_i18n.py` and `locale_v1 --all` pass; `cargo test`, `render_check.js`
   headless, and the en-XA pseudolocale render are phase proof (established proof stack per CONTEXT.md).
5. **Docs and screenshots out of scope.** Code + catalog + fixtures only (CONTEXT.md locked).
6. **Scope guard.** `src/api.rs` OpenAPI descriptions change ONLY where user-visible and NIM-naming;
   machine contracts (bodies, status codes, content types, metric names/labels, identifiers) do not move
   (AGENTS.md invariant 4).
